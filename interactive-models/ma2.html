Explainer

For the detailed theory behind MA(2) processes, see "Time Series Analysis for Quantitative Finance". For the code behind this window, click the "/." button at "MA(2) Interactive window".

Reading the 3D picture

Each dot is a triple (Yt−2, Yt−1, Yt), and each value is built from the same stream of shocks. Yt and Yt−1 share ϵt−1, and Yt and Yt−2 share ϵt−2, but Yt and Yt−3 share nothing. So MA(2) remembers exactly two steps, and the whole cloud is fixed by three numbers: γ0, γ1 and γ2. There is no regression hyperplane here, unlike AR(2): Yt is not a fixed combination of earlier values, it is a combination of shocks you never observe. Drag to rotate, and use the two View buttons to get the exact 2D shadows of the cloud.

What the 2D views show

In the Yt vs Yt−1 view the tilt of the cloud is ρ1 = θ1(1 + θ2) / (1 + θ1² + θ2²), and in the Yt vs Yt−2 view it is ρ2 = θ2 / (1 + θ1² + θ2²). So θ2 alone decides the sign of the lag-2 tilt, while θ1 decides the lag-1 tilt and the factor (1 + θ2) adjusts its strength: as θ2 goes to −1 the lag-1 link disappears. These correlations are bounded, |ρ1| ≤ 1/√2 and |ρ2| ≤ ½, so the 2D views can never be squeezed into a thin needle. The dot colour follows the sign of ρ1.

Invertibility instead of stationarity

MA(2) is stationary for every θ1 and θ2, so, unlike AR(2), the variance σ²(1 + θ1² + θ2²) is finite everywhere and the ellipsoid never blows up. What can fail is invertibility: the AR(∞) representation exists only inside the triangle θ1 + θ2 > −1, θ2 − θ1 > −1, |θ2| < 1, which is what the badge tracks. Near its edges the AR(∞) weights decay very slowly, and beyond them they grow, so the past can no longer be used to recover the shocks.
Geometrically nothing dramatic happens when you cross an edge, because the cloud only depends on ρ1, ρ2 and the overall size, and replacing a root by its reciprocal leaves these unchanged apart from the size. So invertibility is a convention for choosing one representation, not a visible event in the plot.

Orientation of the ellipsoid

As in the AR(2) page, the covariance matrix of (Yt−2, Yt−1, Yt) is symmetric with equal entries along its diagonals. So (1, 0, −1) is always one axis of the ellipsoid, and the other two axes rotate inside the plane spanned by (1, 0, 1) and (0, 1, 0). Near the edge θ2 − θ1 = −1 the long axis points close to (1, 1, 1), meaning neighbouring values move together, and near the edge θ1 + θ2 = −1 it points close to (1, −1, 1), meaning neighbouring values alternate in sign. Since this comes from symmetry alone, the same alignment appears in AR(2) processes.
