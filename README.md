# Time Series Simulation & Interactive Visualizer

>A visual companion and interactive laboratory for exploring autoregressive and moving average time series models — built to make demonstrations easy and codeless. This is based on the **Python time series library "lagshape"** that I built initially.

---

## 📌 Project Overview & Purpose

> **Note on Architecture:** The interactive HTML pages included here are designed as an **visual aid**. The real core of this project is the **Python library**, where model estimation, mathematical formulation, and series calculations are rigorously implemented via code.

🔗 Quick Links:

- 🐍 **[Core Python Library & Code](https://github.com/kalaapks/lagshape)** — *The core idea.*
- 🌐 **[Interactive Web Visualizations (Live Demo / Index)]()** — *Interactive codeless browser-based simulators.*


The underlying python module does this too using interactive Ploty plots. It also provides simulation and further analysis tools of general ARMA and your own data which these HTML files do not. These HTML interaction just helps us understand the sensitivities of parameters etc.
